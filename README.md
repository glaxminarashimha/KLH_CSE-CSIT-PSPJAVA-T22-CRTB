**Abstract:**
A console-based Java application that simplifies academic course enrollment for college students. It maintains a catalog of courses with code, title, instructor, credits and time slots; lets students register, drop and review enrollments; and automatically builds a weekly timetable grid. Its core strength is proactive clash detection — overlapping slots are rejected before registration is confirmed — alongside semester credit-limit enforcement. Built with object-oriented design, collections and input validation, it demonstrates modular, menu-driven interaction and lays the foundation for a future web-based academic management system.
